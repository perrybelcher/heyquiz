# PDF fonts

Static Noto Sans Regular and Bold from the official NotoSans-v2.015 release. These files are bundled in the server PDF route; generation makes no font-network request. Preserve OFL.txt when redistributing. Exact archive paths, source and SHA-256 hashes are in provenance.json.

Native PDF glyph coverage is checked explicitly. Including these fonts does not imply support for all Unicode scripts or emoji.
