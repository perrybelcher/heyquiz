# Pippi final pre-beta QC — 2026-10-09

## Decision

Conditional readiness for a small supervised beta, not unconditional launch approval. The local core passes broad functional coverage. Production sign-in/AI generation and real external deliveries remain release gates; the saved production credentials were rejected in this session, so an authenticated user session is required to finish those checks. A configured Gemini key is not evidence of a successful generation.

## Corrections and investigations

1. Local Next server traces included local .heyquiz-data records. Added outputFileTracingExcludes for local records, environment files, tests and coverage; rebuilt and verified all 38 server traces with tests/build-packaging.cjs. No environment filenames were found in the original server-trace check. This finding does not establish that production had local records. Four dynamic-filesystem tracing warnings remain, but prohibited files are excluded from the resulting traces.
2. Homepage browser test checked fresh lazy images immediately after return navigation. Diagnostic output identified an unloaded lazy pippi-logo.svg. The test now scrolls each image into view and awaits decode before checking pixels; it passes and still fails for broken images.
3. Marketing brief browser test initially timed out locating the workspace entry. It passed on rerun and again on the rebuilt app. Added explicit authentication-response assertion. The initial cause is not proven; shared rate limiting is a possibility, not a finding. Retain this as intermittent test evidence.
4. A build attempted inside the sandbox stalled; it was stopped, then succeeded outside the sandbox. An API rerun initially targeted its default unused port; rerun with TEST_URL pointed at 3160 passed. Neither is counted as an application failure or additional passed suite.

## Outstanding gates and coverage limits

- Finish real production sign-in, fresh-account confirmation and password recovery on the current release; previous-session reports are not substituted for fresh evidence here.
- Generate at least one real Gemini marketing quiz, review and save it, publish and complete it anonymously. Provider contract/error tests use mocks; no real Gemini call succeeded in this pass.
- Verify a real authorized CRM delivery and retry with a designated test destination. Mock connector coverage does not prove all advertised providers are operational.
- Independent security/code review; load/concurrency testing; screen-reader and physical iOS/Android testing; production database recovery and backup restore were not performed.
- Resolve or accept the documented lint/development-advisory debt with an owner and timeframe.

Recommended next action: independent review using docs/independent-beta-review.md, and complete the production gates before inviting an unsupervised group. No claim of exhaustive testing or absence of defects is made.
