# AI marketing generation QC — 10 October 2026

## Changes

- Invalid JSON or invalid scoring drafts receive at most one fresh generation retry, with schema/validation feedback. Both calls share a 75-second deadline under the route's 90-second limit; each fetch is capped at 40 seconds.
- Requests explicitly allow 16,384 output tokens for longer drafts. Thought parts are excluded; fenced JSON is supported.
- Configuration, quota, network and blocked-content failures do not loop. Rejected drafts are never saved automatically.
- The error panel offers a starter from the current brief. Sign-in guidance appears only for an actual 401 response. Brief and preview remain in session storage; storage failures display a warning.
- Generated recommendation quizzes must have a concrete answer path selecting each result. The conservative witness check can reject complex cross-weighted drafts even if another path exists; it never accepts an unproven target. This check does not restrict hand-edited scoring.
- Provider logs contain only status/category. Validation logs contain issue codes/paths or fixed compiler messages, not brief/model contents.

## Limits

This is three live briefs, not a statistical reliability or load test. Fixture coverage at all lengths does not mean all nine combinations were tested against the live provider. Human editorial review remains necessary. Session storage is tab-local, not a cloud backup. CRM and Stripe were intentionally excluded.
